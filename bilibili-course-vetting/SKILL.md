# B站课程视频质量甄别

> 背景：B站「AI 教程」这类关键词下，高播放的"全100集"视频里很大比例是**课程贩子的搬运引流号**。
> 光看播放量会被骗 —— 128 万播放的可能是纯引流。用下面 6 个指标交叉验证。

## 取证命令（bili-cli，只读无需登录）

```bash
bili video BVxxx                 # 数据 + 字幕可用性
bili video BVxxx --comments      # 评论区（顶层 3 条）
bili user UID                    # UP主签名/等级/硬币
bili user-videos UID -n 15       # 该 UP 的投稿序列 ← 最关键的一步
```

## 6 个红旗指标

### 1. 收藏/点赞 比 > 2.5 倍
正常优质教程大约 1~2。比值高说明"收藏了但没看完"。
```
favorite / like   比值
59240 / 17910  = 3.31   ← 典型收藏即忘
```
配合看：`danmaku / view` 若 < 0.2%（此例 1453/1286409 = 0.11%），说明真实观看互动极低。

### 2. 同一视频反复重发（决定性证据）
`bili user-videos` 里出现 3 条以上**几乎同标题**的稿件，只改几个字或加前缀。
这是"多开副本碰运气上推荐位"的标准打法。

### 3. 标题里藏零宽字符
症状：JSON 里 title 出现 `\uFEFF`（如 `AI Agent开发系统\uFEFF教程`）。
用途是**规避平台标题查重**。看到就是实锤。

### 4. UP主签名用谐音规避审核
典型：`厚台回复："999"整理好的视频配套学习笔记、大模型全套籽料即可获取哦`
「厚台」=后台、「籽料」=资料。签名不带真实身份，只留私域引导 → 卖课导流号。

### 5. 描述/置顶引导去站外
`【视频配套籽料、学习路线、实战项目…请看"置顶平论"自取哦】`
正规教程不会让你去评论区/私信换资料。

### 6. 卖课话术关键词
「学完薪资翻倍」「学完即就业」「少走99%的弯路」「存下吧」「允许白嫖」「吊打付费」
出现 ≥2 个基本可判为引流。

## 判决口径
- **命中 1~2 条**：存疑，看评论区是否有真实学习者提问/纠错。
- **命中 3 条以上**：引流搬运号，不建议投入时间，直接换人。
- 反向可信信号：UP 实名/长期更新、有专栏或代码仓库、评论区在讨论技术细节而非"求资料"。

## 已知的可信替代方向（B站）
优先找**实名技术博主**或**官方账号**，而不是"XX教程"命名的机构号。
对比：`程序员鱼皮`（实名校验，单集式，16 分钟）、`从零学AI_李沐`（挂李沐名号，播放低但来源可溯）。
