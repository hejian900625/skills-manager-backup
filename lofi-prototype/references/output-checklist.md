# 交付自检清单

生成原型后逐项打勾，全部通过才可交付评审。

## A. 视觉与配色
- [ ] 全站只有灰阶 + 白 + `#d93025`，无第二种色相
- [ ] 红色仅出现在「必填/校验错误/危险操作/异常标签/待确认批注/热区」六类场景
- [ ] 层级靠填充深浅、描边深浅、字重表达，而非颜色
- [ ] 无装饰性色块、无渐变、无彩色图标

## B. 自适应
- [ ] 三档视口（1440 / 768 / 375）逐一切换检查，无横向滚动条（表格除外，允许自身横向滚动）
- [ ] 平板档卡片栅格降为 2 列，内容内边距 16
- [ ] 移动档：侧边导航收进抽屉、卡片单列、表格转卡片列表、底部标签栏出现
- [ ] 移动档控件高度升档（32→40），按钮在弹窗脚/表单中平分为全宽
- [ ] 切换视口时元素间距与对齐关系保持稳定，无重叠、无挤压

## C. 组件一致性
- [ ] 同类组件复用同一 class，无内联 `style` 写死尺寸/颜色（临时占比位除外）
- [ ] 按钮层级正确：每屏主按钮 ≤1 个
- [ ] 所有控件高度取自 28/32/40 三档，无自定义高度
- [ ] 所有间距取自 4pt 栅格变量
- [ ] 图标统一为线性 SVG，线宽一致

## D. 交互完整性
- [ ] 每个可点击元素都有 `data-goto` 或其它 `data-*` 行为，无死链
- [ ] 每个页面都有 `data-pid`（P1…Pn）与 `data-title`
- [ ] 每个页面至少覆盖一种异常态（空/加载/错误/禁用/无权限）
- [ ] 表单有校验：必填标红、错误提示、聚焦首个错误项
- [ ] 破坏性操作有二次确认，文案说明不可恢复
- [ ] 弹窗/抽屉可用按钮、遮罩、ESC 三种方式关闭
- [ ] hover / focus / selected / disabled / loading / error 六态可实际演示

## E. 结构与可评审性
- [ ] 有 P0 流程总览页，节点编号与页面编号一致且可点击跳转
- [ ] 流程箭头上标注了触发条件
- [ ] 待确认项用红色批注 `.anno-red` 标出
- [ ] 页面顶部有浏览器模拟栏，可返回、显示当前页面编号
- [ ] 交付说明包含：组件规范、配色规则、交互设计依据三段

## F. 技术
- [ ] 单文件/单目录可直接双击打开，无外部 CDN 依赖
- [ ] HTML 标签闭合正确，JS 无语法错误（`node --check lofi.js`）
- [ ] 打印样式可用（评审现场可直接 Ctrl+P 导出 PDF）
