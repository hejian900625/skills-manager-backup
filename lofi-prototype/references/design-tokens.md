# 设计令牌（Design Tokens）

所有数值已固化为 `assets/lofi.css` 的 CSS 变量。**禁止在页面里写死色值/尺寸**，一律 `var(--xxx)`。

## 1. 配色（配色铁律：灰阶 + 单红）

| 用途 | 变量 | 色值 |
|---|---|---|
| 标题 / 反色文字 / 强调 | `--ink-900` | `#111111` |
| 正文 | `--ink-700` | `#3d3d3d` |
| 次要正文 | `--ink-600` | `#5c5c5c` |
| 辅助说明 / 占位旁注 | `--ink-500` | `#767676` |
| 占位符 placeholder | `--ink-400` | `#9a9a9a` |
| 禁用文字 | `--ink-300` | `#bfbfbf` |
| 强调描边（聚焦/选中/表头） | `--line-strong` | `#8c8c8c` |
| 常规描边（输入框/按钮/卡片） | `--line` | `#c9c9c9` |
| 分隔线 | `--line-soft` | `#e4e4e4` |
| 页面底 / 表头底 | `--fill-50` | `#fafafa` |
| hover 底 / 斑马纹 | `--fill-100` | `#f4f4f4` |
| pressed / 选中底 | `--fill-150` | `#ededed` |
| disabled 底 | `--fill-200` | `#e2e2e2` |
| 骨架屏条 | `--fill-400` | `#bdbdbd` |
| **主操作底 / 反色底** | `--fill-900` | `#2b2b2b` |
| 画布 | `--paper` | `#ffffff` |
| **唯一彩色：警告/错误/破坏性** | `--danger` | `#d93025` |
| 危险描边 | `--danger-line` | `#f0a9a3` |
| 危险底 | `--danger-fill` | `#fdecea` |
| 遮罩 | `--mask` | `rgba(17,17,17,.45)` |

**红色使用白名单（除此之外一律灰阶）**
1. 必填星号 `*` 与校验错误文案/描边
2. 危险按钮（删除、停用、驳回等不可逆操作）
3. 错误 / 异常 Alert、Toast 的 error 类型
4. 表示异常的标签（逾期、失败、已锁定）
5. 原型批注中的「待确认 / 风险」项（`.anno-red`）
6. 热区标注虚线框（`.hotspot`）

**禁止**：用红色表达成功、用绿色/蓝色/橙色表达任何语义；用色块做装饰。**层级靠「填充深浅 + 描边深浅 + 字重 + 间距」表达。**

## 2. 间距（4pt 基准栅格）

`--sp-1:4` `--sp-2:8` `--sp-3:12` `--sp-4:16` `--sp-5:20` `--sp-6:24` `--sp-8:32` `--sp-10:40` `--sp-12:48`

| 场景 | 规范值 |
|---|---|
| 卡片内边距 | 16 |
| 卡片头部 / 底部内边距 | 12 16 |
| 内容区外边距（桌面/平板/移动） | 24 / 16 / 12 |
| 表单字段垂直间距 | 16 |
| 标签与控件间距 | 6 |
| 按钮内图标与文字 | 6 |
| 栅格槽宽 | 16（移动 12） |

## 3. 字号 / 行高

`11 / 12 / 13 / 14 / 16 / 18 / 20 / 24`，正文行高 1.5，标题行高 1.3。
用途映射：11=角标/页脚；12=表格、辅助文字、标签；13=表单标签、次要说明；14=正文、按钮、导航；16=卡片标题、导航标题、弹窗标题；20=页面 H2；24=页面 H1、统计数值。

字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", Arial, sans-serif`

## 4. 圆角

仅三档 + 全圆：`--r-sm:2px`（按钮/输入框/标签/复选框方框）、`--r-md:3px`（卡片/标签页/面板）、`--r-lg:4px`（弹窗/抽屉）、`--r-full:999px`（单选、开关、头像、徽章、进度条）。
> Axure 风格偏直角，圆角超过 4px 会失去线稿感。

## 5. 栅格与断点

- 12 栏栅格，槽宽 16px；内容最大宽 1200px。
- **响应式一律用容器查询**（相对 `.app` 宽度），因此舞台切换条改宽度时组件会真实重排，而非依赖浏览器窗口。

| 档位 | 宽度 | 布局特征 |
|---|---|---|
| 桌面 | ≥1100px | 侧边导航常驻 208px；卡片 4 列；表格全列 |
| 平板 | 768–1099px | 侧边导航常驻；卡片 2 列；内容内边距 16 |
| 移动 | ≤767px | 侧边导航→抽屉；卡片 1 列；表格→卡片列表；底部标签栏 56px；控件高度升档 |

## 6. 控件高度

| 档位 | 桌面 | 移动（触控档） |
|---|---|---|
| sm | 28 | 32 |
| md（默认） | 32 | 40 |
| lg | 40 | 44 |

其他固定尺寸：顶栏 56（移动 52）、侧边导航项 40（子项 36）、表格行 48（表头 40）、底部标签栏 56、分页按钮 32、标签 20、复选框方框 15、开关 36×20。

## 7. 阴影与动效

- 仅两档：`0 2px 8px rgba(17,17,17,.08)`（卡片 hover）、`0 12px 40px rgba(17,17,17,.22)`（弹窗）。
- 过渡统一 `.12s`（hover/focus）与 `.22s`（位移类如抽屉/侧边栏）。
- 遵循 `prefers-reduced-motion`。
